The seven new logo URLs came from producer-controlled sites and were opened as images. The other 23 remain without a verified new logo. A guessed URL on the Livcheers static host returned HTTP 403 in this environment, so none was added. Existing production logos, if any appear after the snapshot, are preserved by the database merge.

The brand-logo UI no longer constructs a guessed Livcheers URL for an empty logo field. Only the two explicit, previously mapped Livcheers fallback assets remain; existing stored logo URLs still render unchanged.

Pias was considered but not included: the name can refer to a Portuguese wine village, a wine label and a producer, so the exact catalogue identity needs review. Pink Killer replaced that row. Plantation's catalogue slug stays intact; the public guide explains the current Planteray name.

The full-source audit is at `docs/editorial/reports/brand-progress.json`; the batch-only public export is `docs/editorial/reports/batch-33-public-content.json`. The snapshot contains 1,857 rows, of which 678 now have locally authored guides and 1,179 remain outside the authored set. These are catalogue rows, not a deduplicated count of distinct brands. An earlier set of 198 guides still needs full factual revalidation. Structural checks do not prove accuracy, image rights, SEO performance or human authorship.
