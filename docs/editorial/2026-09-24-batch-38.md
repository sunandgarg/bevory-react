## Identity and catalogue follow-ups

- Jinro Chamisul is soju, not sake. The authored category is corrected; the saved live row retains the old category until a separately reviewed catalogue update.
- The `fincas-valdema` row appears to truncate **Fincas Valdemacuco**, Valdemar Family's Ribera del Duero project. The guide uses the verified name while retaining the existing slug/ID to avoid a silent URL change.
- `gunpowder` is identified as **Drumshanbo Gunpowder Irish Gin**, not a generic gin label.
- Several entries are bottle-line labels rather than independent producer companies (Guidalberto, Il Bruciato, Le Serre Nuove, Le Volte, Runcaris). The public copy names the actual producer; catalogue taxonomy needs a separate decision.
- All 30 rows were blank in the saved logo snapshot; the database merge path still preserves any logo already present at publication time.
- Passing the structural audit does not establish factual perfection, image reuse rights, SEO ranking, or AI-detector outcomes. Older guides remain subject to factual review.
